# Roadmap

## Phase 0: Repository initialisation — Current

Create the minimal repository structure and conceptual project documentation.

## Phase 1: Docker-based ROS 2 and Gazebo environment

Define a reproducible containerised development environment after selecting appropriate ROS 2 and Gazebo versions.

## Phase 2: Minimal Gazebo HRI scenario

Create the initial construction-material transport scenario with a mobile robot, human worker, and obstacles.

## Phase 3: Robot state and decision logging

Capture the state relevant to safety decisions and record the actions selected by the robot.

## Phase 4: Causal explanation prototype

Develop an initial mechanism for explaining why a safety-related decision occurred.

## Phase 5: Contrastive and counterfactual explanations

Extend the explanation capability to address alternatives and changes in decision conditions.

## Phase 6: Dialogue interaction and evaluation

Support follow-up explanation questions and evaluate the interactive explanation approach.
